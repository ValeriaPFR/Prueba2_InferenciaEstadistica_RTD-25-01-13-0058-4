# Prueba2_InferenciaEstadistica_RTD-25-01-13-0058-4
Una empresa de tecnología educativa quiere evaluar el nivel de satisfacción de sus estudiantes con un nuevo curso en línea. Para ello, encuestó a 200 estudiantes y obtuvo datos relacionados con: edad, género, puntaje de satisfacción y horas de estudio semanales usando técnicas de estadística inferencial con Python.
